## วิธีอัปโหลดขึ้น GitHub Pages

1. ไปที่ [https://github.com/new](https://github.com/new)
2. ตั้งชื่อรีโป เช่น `countdown-goal` แล้วกด Create repository
3. อัปโหลดไฟล์ `index.html` และ `README.md` นี้เข้าไป
4. ไปที่แท็บ **Settings → Pages**
5. Source เลือก **Deploy from a branch**
6. Branch เลือก `main` โฟลเดอร์ `/ (root)` แล้ว Save
7. รอสักครู่ จะได้ลิงก์ประมาณ
   `https://ชื่อยูสเซอร์.github.io/countdown-goal/`

เปิดลิงก์นั้นแล้วล็อกอินด้วย `PETCH` / `Admin` ได้เลย
